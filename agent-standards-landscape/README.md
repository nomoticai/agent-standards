# Agent Standards Landscape

Community-maintained catalogs of AI agent standardization activity across standards venues: the IETF, W3C, Linux Foundation, IEEE, ISO/IEC, ITU, and industry efforts outside formal SDO governance.

**Master index**: [agent-standards-landscape.md](agent-standards-landscape.md) — the catalog list and the cross-venue findings.

## What this is

Agent standardization is happening in at least six venues at once, and the volume in any one of them has grown past what a single participant can hold in mind. Charter reviews, BoF discussions, project intake, and adoption decisions all benefit from a shared inventory. This directory provides that inventory as a set of continuously updated references, one catalog per venue, with a master index carrying the observations only the combined view can support.

Counts of drafts, projects, and groups are maintained inside the venue files so this page and the master index never date them.

## How the pieces relate

The venue catalogs are descriptive inventories. They list what exists, without comparative claims. The master index is the only place comparative and cross-venue observations appear, and each finding there is written so it can be checked against the venue files. Disagreement with a finding belongs at the index, as an issue or pull request against the specific finding. Disagreement with an entry belongs at the venue file that carries it.

## What this is not

These documents do not advocate for any particular proposal. They inventory what exists so that architectural conversations about scope, overlap, and layer placement can happen with a shared map. Categorization reflects editorial choices some contributors will disagree with; those disagreements are welcome through the routing above.

## How to contribute

**File an issue** for a missing draft, project, or venue; an incorrect categorization; an outdated or superseded entry; or a factual error in a description.

**Open a pull request** for additions, corrections, and description improvements, against the specific catalog file. Entry formats and style conventions are in the repository [CONTRIBUTING.md](../CONTRIBUTING.md).

## Snapshots and citation

The files in this directory are the current source of truth; point to their URLs for the always-current view. Periodic snapshots may be filed as IETF Internet-Drafts under the Independent Submission Stream for citation stability. See [SNAPSHOTS.md](SNAPSHOTS.md) for the snapshot history.
