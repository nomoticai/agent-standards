## Contributors

Substantive contributions are recognized in two places: in the Contributions section of the specific document (rubric depth criteria, suite disputes that changed a document, landscape category work), and here for repository-level recognition. Contributions via pull request automatically enter the git history; entries here recognize work beyond individual PRs.

Contributed material carries its contributor's name in the document it lives in.

*Add yourself via pull request when contributing substantive material.*
